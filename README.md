## `01 // ABOUT THE ENGINEER`

I'm **Aya El Rhorba**, an **AI & Data Science student** interested in the full lifecycle of intelligent applications—from transforming raw datasets and orchestrating distributed pipelines to building predictive models, agentic workflows, APIs and interactive platforms.

My portfolio connects several disciplines through hands-on projects:

- **AI & agentic systems:** retrieval-augmented generation, model evaluation, and automated ML workflows.
- **Data engineering:** distributed processing, streaming ingestion, orchestration, storage, and ML experiment tracking.
- **Applied machine learning:** predictive modeling, deep learning, statistical inference, and uncertainty estimation.
- **Software engineering:** backend services, data-driven dashboards, and multi-agent simulations.
